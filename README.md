# Finance Lab 演示站

Fintechathon 2026 参赛作品的在线演示：<https://lixjanus526-art.github.io/finance-lab-demo/>

- 首页：橙色金属 K 变硬币、液体天平互动
- 个人投资顾问：持仓健康检查、三种方案对照
- 店主财务助手：账单来源核对、现金日历、晚到账试算

本仓库只存放静态构建结果，由团队私有仓库 `codex/kosx-landing-glass` 分支用 `npm run build:static` 生成，请勿直接修改这里的文件。
所有数据均为固定虚构演示数据；计算在浏览器内完成，不连接真实账户或交易，刷新页面会重置操作。
